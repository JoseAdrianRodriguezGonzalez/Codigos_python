La forma BASE s define como
Basic available: Siempre tiene la disponibilidad, de los datos debido a los nodos, ya que guarda constantemente copias
soft state: Datos que cambien con el tiempo, rompiendo la consistencia propia de la base de datos
eventual consistency: Garantiza la consistencia de los datos a lo largo del tiempo,con el tiempo se tiene una propagación y se hacen consistentes
